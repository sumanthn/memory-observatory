## Semantic Extraction Fix Details

**Problem**: Consolidator's fact extraction hit `stop_reason=length` on 4 of 5 sessions:
- Sessions 1, 4: Empty response (0 chars) — model couldn't even start generating
- Sessions 2, 3: Partial JSON (3-7K chars) — truncated mid-object, unparsable

**Root cause**: Prompt asked for "all factual knowledge" — model tried to output 30+ facts as verbose JSON, exceeding 8192 output token limit.

**Fixes applied** (in `memory/consolidator.py`):
1. **Prompt**: "Extract TOP 15 most important facts" + "Keep values concise" — bounds output size
2. **Truncated JSON repair**: New `_repair_truncated_json()` walks backwards through partial JSON to find last complete object, closes the array — salvages partial results as safety net
3. **Max tokens**: Bumped `CONSOLIDATION_MAX_TOKENS` from 8192 → 16384

**Result**: 15 facts extracted per session, clean `stop_reason=end_turn` on all 5.

## Observations

### 1. The 5-session pilot may be too easy
All 3 conditions scored 10.0/10. The scoring criteria use keyword matching (e.g., "covenant", "1.8", "revenue") and the mock tools return deterministic data. Even the no-memory agent can brute-force its way to a perfect score given enough steps. The real differentiation will come at scale (sessions 50+) where the agent needs cross-company recall.

### 2. Step efficiency is the real signal
Quality is a ceiling metric at 5 sessions — all conditions max it out. But step counts vary significantly: full memory saves 40% on Session 4 (targeted recall) and 29% on fresh research (strategy transfer).

### 3. Memory can hurt efficiency
Session 5 shows full memory taking 10 steps vs 5 for no-memory. Hypothesis: procedural memories prompt the agent to do extra checks ("WHEN analyzing a new company THEN also check governance") that inflate step count but don't improve the score.

### 4. Need longer runs to separate conditions
At 5 sessions, the model's stochastic behavior dominates. Previous run had no-memory at 9.2/10, this run at 10.0/10. The 100-session experiment with compounding recall requirements will produce clearer separation.
